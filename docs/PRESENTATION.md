# สคริปต์นำเสนอ Care Companion (~5 นาที)

ห้อง IT309 · 30 ก.ย. · อย่าสุ่มแล้วไม่พร้อม

## 1. ปัญหา (30 วินาที)

ผู้สูงอายุหรือคนที่ครอบครัวไปด้วยไม่ได้ ต้องไปโรงพยาบาล ธนาคาร ราชการ คนเดียว  
เราทำ **เพื่อนเดินทาง** ไม่ใช่แอปพยาบาล

## 2. ใครใช้ (20 วินาที)

- Customer สร้างคำขอ
- Companion รับงานหลังแอดมินอนุมัติ
- Admin ดูแลผู้ใช้และคำขอ

## 3 เดโมสด (3 นาที) — เปิดแท็บไว้ก่อนขึ้นพูด

1. หน้าแรก: หัวข้อ “ไม่ต้องเดินทางคนเดียว” + สลับไทย/อังกฤษ
2. ล็อกอิน Google (Customer) → สร้างคำขอ ปักหมุดแผนที่
3. เปิดรายชื่อ Companion แบบป้ายทะเบียน → เชิญ
4. สลับบัญชี Companion → ตอบรับ → แชท
5. เริ่มเดินทาง → จบงาน → ให้คะแนน
6. สลับ Admin → อนุมัติ/ระงับผู้ใช้

ถ้าเน็ตล่ม: เปิดหน้าแรก + เล่า flow จากสกรีนช็อตที่เซฟไว้ในโทรศัพท์

## 4. เทคนิคที่ต้องพูด (45 วินาที)

- Next.js App Router + Tailwind
- Google + Supabase Auth
- PostgreSQL มี RLS แยกสิทธิ์ตามบทบาท
- Storage รูปโปรไฟล์
- จับคู่แบบผสม: ระบบแนะ + เลือกเอง + Companion สมัคร
- ค่าตอบแทนระบุในคำขอ จ่ายนอกระบบ
- Deploy Vercel

## 5. สิ่งที่ไม่ได้ทำ (10 วินาที)

ไม่มี payment gateway — ตามโจทย์ไม่บังคับ และจะไม่ทันถ้าทำ

## สำรองถ้าสุ่มแล้วเครื่องค้าง

เปิดลิงก์ Vercel จากโทรศัพท์ เดโมมือถือทันที
